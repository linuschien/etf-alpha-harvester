### 2.4 全球 5 大基準指數走勢 ＆ 黃金分割回撤雷達 (Benchmark Drawdown Radar)
* **設計規範**：
  - **單一市場聚焦**：不疊加多國指數（避免蜘蛛網與非同步休市斷點），上方提供基準切換鈕，**預設為 `^TWII 台灣加權指數`**。
  - **跨國休市日平滑**：採金融標準「前值平滑遞延 (LOCF)」，休市日自動延續前一交易日收盤價。

## 5. 異常、加載與空值狀態 (Loading, Error & Empty States)

1. **加載狀態 (Loading Skeleton)**：
