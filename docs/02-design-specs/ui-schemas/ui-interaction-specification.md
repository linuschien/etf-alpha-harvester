# UI 元件互動與操作行為規格書 (UI Component & Interaction Specification)

本文件明確定義「全球市場情報 (Global Market Intelligence)」畫面中**所有元件的視覺型態（哪些是 Label / Badge，哪些是 Button / Switch / Tab）**、**預設狀態**、**操作觸發事件**以及**按下後的具體行為與視覺反饋**。

## 5. 異常、加載與空值狀態 (Loading, Error & Empty States)

1. **加載狀態 (Loading Skeleton)**：
   - 首次載入或切換頁籤時，各卡片與表格呈現灰色脈衝骨架屏（Skeleton），避免白屏或內容跳動。
2. **錯誤提示 (Error Toast & Alert)**：
   - 網路異常或後端逾時（5xx）時，由頂部彈出錯誤 Toast，顯示具體錯誤原因與「重試」按鈕，嚴禁僅顯示裸露狀態碼。
3. **空值狀態 (Empty State)**：
   - 若某資產池篩選條件無符合標的，表格中央展示 Empty State 插圖與文字提示（如「查無合規標的，請切換種子或篩選條件」）。
