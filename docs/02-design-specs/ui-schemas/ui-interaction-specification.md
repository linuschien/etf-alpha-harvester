### 2.4 全球 5 大基準指數走勢 ＆ 黃金分割回撤雷達 (Benchmark Drawdown Radar)
* **設計規範**：
  - **單一市場聚焦**：不疊加多國指數（避免蜘蛛網與非同步休市斷點），上方提供基準切換鈕，**預設為 `^TWII 台灣加權指數`**。
  - **跨國休市日平滑**：採金融標準「前值平滑遞延 (LOCF)」，休市日自動延續前一交易日收盤價。
  - **均線連續性保證**：後端預熱載入 2 年歷史資料，在 **`6M` 與 `1Y` 視窗下**，240MA（年線）自第一天起即可 100% 連續平滑繪製，杜絕開頭 240 天無均線的空白斷層。

## 5. 異常、加載與空值狀態 (Loading, Error & Empty States)

1. **加載狀態 (Loading Skeleton)**：
   - 首次載入或切換頁籤時，各卡片與表格呈現灰色脈衝骨架屏（Skeleton），避免白屏或內容跳動。
2. **錯誤提示 (Error Toast & Alert)**：
   - 網路異常或後端逾時（5xx）時，由頂部彈出錯誤 Toast，顯示具體錯誤原因與「重試」按鈕，嚴禁僅顯示裸露狀態碼。
3. **空值狀態 (Empty State)**：
   - 若某資產池篩選條件無符合標的，表格中央展示 Empty State 插圖與文字提示（如「查無合規標的，請切換種子或篩選條件」）。
