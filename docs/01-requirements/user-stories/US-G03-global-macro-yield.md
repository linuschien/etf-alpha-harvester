# US-G03 模組：宏觀利率環境狀態機 (Global Macro Yield Engine)

## 背景 (Background)
本模組為 AlphaHarvester 系統全域層（Global Services）之環境感知大腦。市場利率週期直接決定了股債配置的最佳邊界與利潤流動方向。本模組每日盤後定時抓取 FRED 最新美國投資級公司債到期殖利率 (YTM)，驅動客觀的「三態利率環境狀態機」，對全系統發布全域宏觀狀態、基準股債配比矩陣與黑天鵝救災訊號，指引個人投組層 (P-01, P-02) 進行精確資金分流。

---

## US-G03-01：三態利率環境狀態機自動判定

**身份**：宏觀感知器 (Macro Engine Sensor)

> **As a** 宏觀感知器，  
> **I want to** 每日盤後依據最新美國投資級公司債 YTM 數值自動判定當前所處的宏觀利率狀態，  
> **So that** 系統能以客觀數據引導全體使用者的股債配置節奏，徹底消除主觀升降息臆測。

### 驗收條件 (Acceptance Criteria)
- **AC1 (狀態判定規則)**：每日於 FRED 數據更新後，系統依下列客觀純數值邊界判定 `MacroState`：
  1. **【狀態一：高利蓄水期】(`STATE_1_ACCUMULATE`)**：
     - 判定條件：$\text{US IG Corp YTM} > 5.0\%$。
     - 政策指引：公司債殖利率深具吸引力，債券部位維持積極扣款，動能衛星停利現金 30% 分流注水債券。
  2. **【狀態二：常態平衡期】(`STATE_2_NEUTRAL`)**：
     - 判定條件：$3.5\% \le \text{US IG Corp YTM} \le 5.0\%$。
     - 政策指引：利率處於中性區間，債券停止續扣，安靜領息；每季配息全額回填股票核心大盤。
  3. **【狀態三：低利收割期】(`STATE_3_HARVEST`)**：
     - 判定條件：$\text{US IG Corp YTM} < 3.5\%$。
     - 政策指引：降息循環尾聲、債券價格大幅膨脹，債券部位觸發「停利不續扣」，分批出清債券部位實現資本利得，資金 100% 轉投股票核心大盤。
- **AC2 (客觀無狀態判定 - 純閥值邊界)**：
  - 狀態機採用無狀態純函數判定，不引入遲滯緩衝區（Hysteresis Band），直接依據當日殖利率落點計算對應狀態與建議股債配置比例。
- **AC3 (狀態廣播與歷史存檔)**：最新狀態與 YTM 數值寫入 `MacroYieldSnapshot`，並於雲端戰情室首頁全域展示。

## US-G03-02：全域股債動態基準配比矩陣與黑天鵝逆向救災協議

**身份**：風控調度器 (Risk Governance Dispatcher)

> **As a** 風控調度器，  
> **I want to** 根據當前宏觀狀態發布全域股債基準配比矩陣，並在核心大盤發生極端暴跌時啟動黑天鵝救災覆寫訊號，  
> **So that** 個人投組層能根據全局風控指令自動調整資產防禦深度與逆向抄底強度。

### 驗收條件 (Acceptance Criteria)
- **AC1 (全域股債基準配比矩陣發布)**：
  - `STATE_1_ACCUMULATE`（高利蓄水期）：股票基準 80%，防禦債券基準 20%。
  - `STATE_2_NEUTRAL`（常態平衡期）：股票基準 85%，防禦債券基準 15%。
  - `STATE_3_HARVEST`（低利收割期）：股票基準 95%，防禦債券基準 5%。
- **AC2 (黑天鵝逆向救災階梯監控)**：
  - 系統每日監控核心大盤（以 0050 為基準）自近 52 週最高收盤價之累計回撤度（Drawdown, DD）：
    $$\text{DD}_{\text{core}} = \frac{P_{\text{close}} - \max_{252}(P)}{\max_{252}(P)}$$
  - **-10% 修正期**：保持常態紀律，維持原定策略不變，定期定額靜默扣款。
  - **-15% ~ -20% 空頭恐慌期（一級逆向單筆抄底訊號）**：當核心大盤回撤達標且 VIX $\ge 30$（或科技衛星回撤且 VXN $\ge 35$）時，系統發布 `CRISIS_LEVEL_1` 警告。鑑於 VIX 脈衝均值回歸極為迅速（3~5 日內反彈），系統放棄緩不濟急的「調整次月定期定額額度」，直接發布【單筆超跌加碼工單】，引導投資人調用交割戶停利閒置現金，以 1 整張（1,000 股）為單位單筆市價撈底 0050 或 00757，精準把握流動性錯殺買點。
  - **-30% 斷崖黑天鵝期（終極救災條款）**：系統發布 `CRISIS_LEVEL_2` 救災訊號，強制發布指令：建議自個人防禦債券池套現 50% 本金部位，分批單向市價注入 0050 等核心大盤標的。
- **AC3 (救災解除機制)**：當核心大盤價格自低點反彈回升至波段高點回撤率 $< -15\%$ 且連續維持 20 個交易日時，系統自動解除救災覆寫，回歸常態宏觀狀態機管理。
