## 1. 產品定位與設計哲學 (Design Philosophy & Beginner UX)

### 1.1 核心理念
1. **客觀定錨，消滅 FOMO 與恐慌**：
   - 不提供任何短期價格走勢預測或主觀猜測。
   - 所有指標均為客觀市場數據（收盤行情、期權隱含波動度、FRED 利率指標、公開除息公告）與純數學多因子模型產出。
2. **純淨零雜訊原則 (100% Qualified Only)**：
   - 全台超過 350 檔 ETF 中，超過 80% 屬於高費用、小規模或每日重置槓桿反向商品。
   - **UI 預設 100% 徹底隱藏未通過硬約束篩選之淘汰標的**，各分頁只呈現通過嚴格檢驗之頂尖菁英標的，徹底消滅小白使用者的認知過載。
3. **直觀三色警戒系統 (Traffic Light Color System)**：
   - 揚棄需要心算的複雜公式與百分比，全面轉化為視覺直觀顏色：
     - 🟢 **綠色 (Safe/Opportunity)**：環境安全、或超跌黃金買點浮現。
     - 🟡 **黃色 (Neutral/Observation)**：常態平衡期、定期定額維持靜默扣款。
     - 🔴 **紅色 (Alert/Caution)**：極度貪婪警訊、或 ETF 盤中溢價過高。
4. **意圖揭露，拒絕晦澀金融黑話**：
   - 嚴格落實 Clean Code 命名哲學，所有介面文字均採用自我意圖揭露（Intention-Revealing）之白話詞彙（例如以「總費用率」取代 TER、以「基金規模」取代 AUM、以「還原收盤價」取代 Adj Close）。

### 3.3 Tab 2：合規標的天梯榜與配置決策雷達 (Qualified Asset Leaderboard & Allocation Radar)

#### 1. 設計原則與純淨過濾
* **100% 嚴格過濾**：僅收錄通過 Stage 1 動態數值門禁之合格候選標的。徹底剔除未滿 365 日曆天/220 交易日、AUM < 20 億（對接 TWSE MIS 即時淨值與單位數計算）、30 日成交額中位數 < 2,000 萬、或門禁落選之次級標的。
* **三大合規資產分類 (Candidate Asset Classes - 嚴格三池定義)**：
  系統底層與介面**嚴格限定為以下 3 類資產池**，絕無 `TECH（科技）` 或 `HIGH_DIVIDEND（高股息）` 獨立資產池（此類主題僅為動能衛星池內部自然分群形成的子賽道，非候選池分類）：
  - `核心大盤 (Core Top 10)`：全市場與台灣加權指數 $R^2_{\text{TAIEX}} \ge 0.90$ 之頂尖 10 檔，永不主動清倉，終身穩健複利底座。評分模型為：
    $$\text{Score}_{\text{CORE}} = \frac{1}{3} \text{Rank}(R^2_{\text{TAIEX}}) + \frac{1}{3} \text{Rank}(\text{DCA}) + \frac{1}{3} \text{Rank}(\text{AUM}) \quad (\text{無報酬率、無夏普})$$
  - `動能衛星 (Satellite Top 50)`：排除核心與債券，門禁條件為近一季 $\sigma_{90d} \ge 18\%$ 且 $\text{MOM}(12\text{M}) > 0$ 之高波衝鋒 50 檔。評分模型為：
    $$\text{Score}_{\text{SATELLITE}} = 50\% \text{Rank}(\text{MOM}_{12\text{M}}) + 25\% \text{Rank}(\text{KER}) + 25\% \text{Rank}(\text{Sharpe}) \quad (\text{無 AUM、排除大盤影子})$$
  - `防禦債券 (Defensive Top 5)`：純現券型投資級/公債 ETF Top 5（一票否決排除非投資等級債），直接由 Top 1 標的入選投組。評分模型為：
    $$\text{Score}_{\text{DEFENSIVE}} = 70\% \text{Rank}(\text{YTM}) + 30\% \text{Rank}(\text{AUM}) \quad (\text{無報酬率、無定額戶數})$$
* **雙重視角決策切換器 (Perspective Mode Toggle)**：
  在組別頁籤下方提供核心視角切換器，滿足投資人在「幾何波動收割」與「賽道去冗餘」兩種不同場景下的決策需求：
  - `[ ⚡ 夏農模式 (幾何收割) (選中) ]`：目標為尋求兩兩低相關（$R^2 < 0.50$）的資產組合，以極大化再平衡之夏農波動收割（Shannon's Demon）。
  - `[ 🧩 分群模式 (去冗餘族群) ]`：目標為將走勢高度同質（$R^2 \ge 0.80$）的 ETF 歸組，選取動能評分最高者為群組首選（Leader），客觀呈現同質替代標的與量化數據，由使用者自主決斷去冗餘。

#### 2. 視角一：⚡ 夏農模式 (Shannon Mode - 幾何正交配置視圖)

##### 1. 極簡互動正交引擎 (Zero Mode Toggle - 點擊即錨定)
* **無需複雜選單**：載入時預設錨定該池第一名標的（`#1` Rank 1 為初始種子）。
* **點擊即切換錨點 (Click to Anchor)**：使用者點擊榜單上的任何一檔 ETF，即自動將該標的設為新的「錨定種子」（標記 🟢 `[錨定種子]` 膠囊），系統即時重新計算池內所有標的之正交入選與共線排除狀態。
* **輔助控制鈕**：
  - `[ ↺ 重設為 Rank 1 種子 ]`：一鍵復原為第一名初始種子。
  - `[ 📊 查看兩兩正交矩陣 (Pairwise Matrix) ]`：展開彈窗檢視兩兩 $R^2$ 與相關係數 $\rho$ 矩陣熱圖。

##### 3. 兩兩正交檢驗矩陣熱圖視圖 (Pairwise Matrix Heatmap Modal)
* **呼叫途徑**：點擊天梯榜工具列之 `[ 📊 查看兩兩正交矩陣 (Pairwise Matrix) ]` 按鈕，彈出全域對話框 (`pairwise-matrix-modal`)。
* **顯示範圍控制項 (Scope Selector)**：
  - 當候選池標的數 $> 10$ 檔時：提供三段切換按鈕 `[ 前 10 檔 (Top 10) ]`、`[ 前 20 檔 (Top 20) ]`、`[ 全部標的 (N 檔) ]`，支援快速降維綜覽與全量交叉排查。
  - 當候選池標的數 $\le 10$ 檔時（如核心大盤池）：鎖定呈現 `全數顯示 (共 N 檔)` 標籤。
* **標的搜尋過濾與十字高亮 (Search & Highlight)**：
  - 提供 `[ 搜尋標的代碼 (如 0052)... ]` 輸入框與 `[ ✕ 清除 ]` 按鈕。
  - 輸入代碼時，表格 X 軸（目標）與 Y 軸（基準）標頭即時以主色實心深色反白高亮，便於快速定位該標的之交叉相關度。
* **4 大 KPI 統計膠囊 (Summary KPI Badges)**：
  1. `當前矩陣標的`：$N$ 檔
  2. 🟢 `夏農正交組合`：$R^2 < 0.50$ 對數與佔比（綠色高亮膠囊，表示具幾何互補性的夏農再平衡黃金組合）
  3. ⚪ `中性常態連動`：$0.50 \le R^2 < 0.80$ 對數與佔比（中性溫和膠囊，表示屬同市場常態 Beta 連動，非正交亦非同質冗餘）
  4. 🟣 `高度共線組合`：$R^2 \ge 0.80$ 對數與佔比（紫色警示膠囊，表示走勢高度同質重疊，分群模式下觸發替代合併）
* **雙向凍結窗格與三態熱圖色階 (Sticky Frozen Panes & 3-Tier Heatmap Grid)**：
  - **凍結窗格**：左上角 `基準 \ 目標` 儲存格雙向凍結，首列標頭置頂凍結、首行代碼置左凍結，滾動時座標軸不遺失。
  - **自相關對角線**：同一標的自身對角線數值固定為 `1.00`，以次要灰色底色呈現。
  - **非對角線單元格（嚴格三段式劃分）**：
    - 🟢 **夏農正交 ($R^2 < 0.50$)**：以綠色階顯示，數值越低（正交性越高）綠色越鮮明。
    - ⚪ **中性連動 ($0.50 \le R^2 < 0.80$)**：以中性淺色填充，僅呈現數值，不標註任何警告標籤。
    - 🟣 **高度共線 ($R^2 \ge 0.80$)**：以紫色階高亮顯示，數值下方標記「共線」紅色警告標籤。
  - **懸停檢視 (Hover Inspection)**：滑鼠懸停於單元格時即時浮現 Tooltip，揭露基準標的、目標標的、判定係數 $R^2$、相關係數 $\rho$ 及精準的三態判定回饋：
    - $R^2 \ge 0.80$：`🟣 高度共線 (R² ≥ 0.80) — 走勢高度同質，分群模式觸發替代歸組`
    - $0.50 \le R^2 < 0.80$：`⚪ 中性連動 (0.50 ≤ R² < 0.80) — 常態市場連動，非正交收割亦非同質冗餘`
    - $R^2 < 0.50$：`🟢 夏農正交 (R² < 0.50) — 具幾何互補性，適合夏農再平衡收割`
* **防禦債券防呆**：
  若在防禦債券（純公債與投資級公司債）分組下開啟矩陣，因純債券無需幾何正交去共線，畫面展示友善說明：「尚無兩兩正交檢驗矩陣資料（債券防禦型標的無需共線剔除）」。

#### 3. 視角二：🧩 分群模式 (Clustering Mode - 階層式可展開表格視圖)

##### 1. 設計原則與互動規格
* **完全去冗餘主表架構 (Zero-Redundancy Master Rows)**：
  - 為杜絕「26 個獨立賽道卡片造成版面過度冗長與空洞」，本模式維持與夏農模式一致的金融專業表格骨架。
  - **表格主列預設僅顯示各賽道之「👑 群組首選 (Leader)」**：全池 40 檔候選標的預設收斂為 30 行，使用者一眼即可綜覽 30 個獨立賽道動能首選，達成極致去冗餘與高資訊密度。
* **首選角色與折疊指示標籤**：
  - 👑 **`[▼/▶ 👑 首選 (+N 檔同質替代)]`**：若該 Leader 擁有被吸納的同質替代標的（$R^2 \ge 0.80$），行首呈現折疊/展開按鈕（`▶` 預設收合 / `▼` 點擊展開），並標記同質替代標的檔數。
  - ✨ **`[✨ 獨立賽道]`**：若該標的無任何同質替代標的（26 個 Singletons），直接標註為獨立賽道，無折疊按鈕。
* **就地展開灰色縮排子列 (Inline Collapsible Sub-rows)**：
  - 點擊行首之折疊按鈕 `▶`，就地在該主列下方展開具有淺灰色背景的縮排子列區塊（Sub-rows）。
  - **客觀量化數據純展示**：清楚列出每檔被吸納之替代標的客觀數值：
    - `組內排名` (如 `Rank #2`)
    - `標的代碼/名稱` (如 `[00935] 野村臺灣創新科技50`)
    - `最新市價` (如 `24.50`)
    - `多因子評分差距` (如 `評分 85.3 (落後首選 0.6 分)`)
    - `與首選之決定係數` (如 `R² = 0.846 (日常走勢同步率 92%)`)
    - `追蹤指數名稱` (如 `臺灣上市上櫃FactSet創新科技50指數`)
  - **無主觀操作指導**：純粹揭露同質標的之量化關聯與統計事實，不提供任何主觀買賣或換檔提示條，讓使用者依客觀數據自主決斷。
* **全域排序相容性**：
  - 支援點擊表頭（1M / 3M / 6M / 1Y / 規模 / 評分）雙向排序。主列依選定指標重排時，展開之替代子列緊隨其母體 Leader 連動，確保資訊脈絡不中斷。

#### 4. 標的詳細資訊抽屜 (Asset Detail Drawer)
* 點擊任一標的列，自右側滑出抽屜，展示四大模組：
  1. **基本檔案與配息政策**：發行投信、追蹤指數、掛牌日期、累計日曆天年資、最新 NAV、發行單位數、動態 AUM、法定配息週期。
  2. **多因子得分拆解雷達圖 (Spider Radar Chart - 各池專屬因子 Percentile Rank)**：
     - **核心大盤 (Core)**：$\text{Rank}(R^2_{\text{bench}})$（貼合度）、$\text{Rank}(\text{DCA})$（定額戶數）、$\text{Rank}(\text{AUM})$（規模深度）。
     - **動能衛星 (Satellite)**：$\text{Rank}(\text{MOM})$（12-1月動能）、$\text{Rank}(\text{KER})$（考夫曼效率比）、$\text{Rank}(\text{Sharpe})$（純年化夏普）、$(1 - R^2_{\text{TAIEX}})$（大盤去影子）。
     - **防禦債券 (Defensive)**：$\text{Rank}(\text{YTM})$（實質年化現金殖利率）、$\text{Rank}(\text{AUM})$（資產規模）。
  3. **歷史 Raw Close 日 K 線與技術分析系統（圖表規格 100% 同大盤指數）**：
     - **時間視窗**：預設 **`6M`**，工具列支援 `[ 1M | 3M | 6M (預設) | 1Y ]` 自由切換。
     - **標配四條生命線**：🟡 20MA（月線）、🟣 60MA（季線）、🟠 120MA（半年線）、🔵 240MA（年線，後端 2 年 DB 歷史無縫預熱，保證首日連續無缺口）。
     - **標配月線布林通道 (20MA $\pm 2\sigma$)**：上下軌間填充淺藍色半透明帶狀陰影 (Band Cloud)；收盤跌穿下軌時下軌轉為綠色高亮。
     - **標配黃金分割回撤防線**：-23.6%（呼吸區）、-38.2%（撈底線）、-50.0%（多空平衡線）、-61.8%（極端超跌坑）、-76.4%（黑天鵝救災線）。
     - **工具列獨立開關**：`[ 均線 (MA) ✓ ]` `[ 布林通道 (BB) ✓ ]` `[ 黃金分割線 (Fib) ✓ ]`，支援 LocalStorage 記憶偏好。
  4. **🎯 超跌加碼勝率評分卡片 (Dip-Buying Opportunity Score, $S_{\text{dip}} \in [0, 100]$)**：
     - 由記憶體純函數 (Pure Function) 依最新市場數據即時運算，以四維信號共振求解單筆加碼之歷史勝率與安全邊際：
       $$S_{\text{dip}} = \underbrace{S_{\text{bollinger}}}_{\text{統計維度 (30%)}} + \underbrace{S_{\text{fibonacci}}}_{\text{空間維度 (25%)}} + \underbrace{S_{\text{ma\_support}}}_{\text{趨勢維度 (25%)}} + \underbrace{S_{\text{panic}}}_{\text{情緒維度 (20%)}}$$
     - **四維度打分準則**：
       - ① **統計維度 ($S_{\text{bollinger}}$, 30分)**：布林通道位置 $\%B = \frac{\text{Price} - \text{Lower}}{\text{Upper} - \text{Lower}}$。$\%B \le 0.0$ (跌穿下軌) 得 30 分；$0.0 < \%B \le 0.15$ 得 20 分；$0.15 < \%B \le 0.30$ 得 10 分；$\%B > 0.5$ 得 0 分。
       - ② **空間維度 ($S_{\text{fibonacci}}$, 25分)**：52 週回撤率。跌幅 $\ge 38.2\%$ 得 25 分；$23.6\% \le \text{跌幅} < 38.2\%$ 得 20 分；$14.6\% \le \text{跌幅} < 23.6\%$ 得 12 分；$< 10\%$ 得 0 分。
       - ③ **趨勢維度 ($S_{\text{ma\_support}}$, 25分)**：四條均線乖離與支撐。跌破年線 (240MA) 且負乖離 $\le -5\%$ 得 25 分；跌破半年線 (120MA) 或回踩年線支撐得 18 分；跌破季線 (60MA) 或回踩半年線得 12 分；均線多頭排列得 0 分。
       - ④ **情緒維度 ($S_{\text{panic}}$, 20分)**：期權恐慌與貪婪指數。VIX $\ge 35$ (或科技衛星 VXN $\ge 40$) 得 20 分；$30 \le \text{VIX} < 35$ (或 CNN 貪婪 $< 20$) 得 15 分；$25 \le \text{VIX} < 30$ 得 8 分；VIX $< 20$ 得 0 分。
     - **得分評級與勝率階梯表**：
       | 得分 ($S_{\text{dip}}$) | 訊號燈與評級 | 歷史 1 年持有正報酬勝率 (大盤型) | 系統建議動作 |
       | :--- | :--- | :--- | :--- |
       | **80 ~ 100 分** | 🟢 **【五星黃金坑】** | **$\ge 90\%$** | **單筆加碼最佳時機！** 產生單筆超跌工單，調用交割戶停利閒置資金果斷撈底。 |
       | **60 ~ 79 分** | 🟢 **【四星超跌區】** | **$75\% \sim 85\%$** | **具備高度安全邊際**。提示可分批加碼，或調高下期定期定額注資金額。 |
       | **40 ~ 59 分** | 🟡 **【三星平穩區】** | **$60\% \sim 70\%$** | **常態健康回檔**。嚴格維持紀律，日常定期定額靜默扣款，不需額外加碼。 |
       | **0 ~ 39 分** | ⚪ **【低星觀望區】** | 市場估值偏高 | **嚴禁單筆追高加碼**，避免高基期接刀。 |

## 4. 狀態管理與異常邊界處理 (State & Edge Cases)

| 狀態場景 | 前端視覺反饋 | 處理邏輯 |
| :--- | :--- | :--- |
| **加載中 (Loading)** | 骨架屏 (Skeleton Screens) | 載入時保留卡片與表格骨架，防止佈局跳動 (Layout Shift)。 |
| **外部休市或無新行情** | 沿用最新收盤數據 | 由後端資料庫水位線與守門員把關，前端不主動猜測各國節假日行事曆，純粹依據 Watermark 與持久化收盤價客觀呈現。 |

| **除息清單模式查無標的 (No Match State)** | 柔和紅色警示卡片 | 提示「⚠️ 查無標的「{searchedTicker}」的除息或分割記錄，請確認輸入之代碼是否正確」。 |
| **月曆跨頁籤靜默防護 (Tab Inactive)** | 無視覺負擔 (Zero Fetch) | 當活動頁籤非除息月曆時，元件嚴格保持靜默，不向後端發出 GraphQL 請求。 |

## 6. 驗收標準 (Acceptance Criteria)

1. **零雜訊驗收**：天梯榜上所有標的皆為通過 Stage 1 門禁之合格標的，絕無淘汰標的；資產分類嚴格鎖定「核心大盤 Top 10」、「動能衛星 Top 50」、「防禦債券 Top 5」，系統絕無獨立之 TECH 或 HIGH_DIVIDEND 候選池。
2. **正交去共線與矩陣驗收**：
   - 預設模式 A 標記 Rank 1 為種子，向下全量標示 `ACCEPTED` 或 `REJECTED_COLLINEAR`，並於 Tooltip 顯示衝突對象與 $R^2$。
   - 切換模式 B 可自選 Top 清單種子 S 置頂，系統動態重算正交狀態與衝突來源。
   - 點擊「查看兩兩正交矩陣」能完整載入並視覺化呈現熱圖，支援 Top 10 / Top 20 / 全部切換、標的代碼搜尋高亮、4 大 KPI 統計膠囊（當前標的、🟢 夏農正交佔比、⚪ 中性連動佔比、🟣 高度共線佔比）與雙向凍結窗格。
3. **多天期績效驗收**：1M, 3M, 6M, 1Y 績效必須嚴格依據 Raw Close 與配息現金零誤差加總法計算，支援點擊表頭雙向排序；未達天期標的以 `--` 容錯展示。
4. **四條均線與布林通道驗收**：5 大基準走勢圖與抽屜 K 線圖必須完整繪製 20MA、60MA、120MA、240MA，月線布林通道 ($20\text{MA} \pm 2\sigma$) 必須以半透明色塊完整填充，跌破下軌時能清晰變色提示。
5. **超跌加碼勝率評分驗收**：加碼評分 $S_{\text{dip}}$ 必須嚴格由四維度（統計 30%、空間 25%、趨勢 25%、情緒 20%）純函數求解，總分落在 0~100 區間，並能準確映射至星級、歷史勝率與建議工單。
6. **除息與分割視圖驗收**：
   - **月曆模式**：按月 Lazy Loading 延遲載入；後端 Spring Data 原生 OR 衍生查詢無遺漏當月發放標的；單元格事件優先級（🟣分割置頂 > 🟢除息 > 🔵發放）；明細卡片僅展示精簡標的代碼；徹底移除頻率下拉選單。
   - **清單模式**：提供標的代碼文字精準搜尋與一鍵清除；預設空狀態指引不無腦拉取 1,800+ 筆資料；除息日與發放日配對為單列展示（5 大欄位）；日期倒序 DESC 排列；前端記憶體共用分割事件。
   - **可見性防護**：非除息月曆頁籤保持靜默，首頁不預先載入無過濾之全量除息公告。
7. **數據水位線驗收**：頁首膠囊點擊開啟水位對話框，欄位精準呈現「最近同步筆數」與動態「每日/每月」同步週期徽章。
8. **黃金分割回撤驗收**：回撤圖能準確標記 -23.6%、-38.2%、-61.8% 警戒線，並能平滑切換整數閥值與單一市場基準。
9. **權限隔離驗收**：後端維運端點具備權限隔離，前端維運頁面現階段暫緩建置，日常使用者無法直接發起後端重算。

## 7. 前端技術架構與部署規範 (Architecture & Deployment)

* **技術棧**：React 18 + TypeScript + Vite + TailwindCSS + Lucide React + Shadcn UI。
* **同源靜態資源部署 (Zero-CORS Architecture)**：
  - 前端編譯產物打包置於 Spring Boot 後端的 `src/main/resources/static/`。
  - 完全由 Spring Boot 統一伺服（Same-Origin），消滅跨網域請求與 CORS 配置複雜度。
* **狀態管理與網路請求**：
  - 採輕量原生或 TanStack Query 發起 GraphQL 查詢，請求路徑為相對路徑 `/graphql`。
